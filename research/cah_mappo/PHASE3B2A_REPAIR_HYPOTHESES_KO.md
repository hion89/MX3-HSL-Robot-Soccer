# 보완 작업 가설 및 최소 실험 — 결과 확인 전 계획

2026-11-18. 기존 소스/출력 보존, 동일 MLP/10개 행동/PPO/보상/학습률 유지. 최종 holdout은 이번 단계에서 실행하지 않는다. 이전 Test는 진단용 개발 자료로만 취급한다.

1. 슬롯 연결 오류와 학습 슬롯 편향을 구분한다. 4대·구역2·작업3의 같은 물리 설정을 고정하고 작업용 논리 슬롯 2/3/4의 6개 순열만 바꾼다. 각 슬롯은 에피소드 내에서 고정한다. 관측 job ID/특징/할당 one-hot/mask/샘플 행동/실행 행동을 함께 변환한다. 역변환한 같은 물리 행동에서 전이·보상이 같아야 한다. 같은 기존 신경망의 작업별 성공이 슬롯 순열에 따라 바뀌면 학습 편향의 증거다.

2. 작업 자체가 불가능한지 먼저 확인한다. 동일 4대 설정을 기존 Exact로 실행한다. 완료 가능성을 확인한 뒤 MAPPO를 고정 조건 → 순열만 변경 → 제한 위치 변화 → 우선순위·마감 변화 순으로 평가한다. 물리 상태와 작업 ID를 슬롯 실험 중 바꾸지 않는다.

3. 정보 부재와 선택 실패를 분리한다. 작업 발생, 로봇별 최초 센서 관측/메시지 수신/Actor 인지, 최초 선택·수락, 대응, 완료·만료 시각을 기록한다. D의 물리·고장·감속 일정은 그대로 두고, 정상 전달(넓은 센서/지연0)과 실제 제한 센서/지연 조건을 비교한다. 통신 지연만의 효과는 동일 센서 조건에서 지연0/2초로 추가 비교한다. 미관측 실패도 전체 성공률에서 제외하지 않는다.

4. 3대 결정적/확률적 차이를 신경망 확률과 행동 전환으로 조사한다. 같은 관측에서 유효 행동 수, 최대 확률, entropy, 작업별 선택 빈도와 log-probability를 기록한다. 초기 선택/최종 checkpoint를 구분한다. 높은 entropy·반복 전환과 작은 PPO KL은 급격한 단일 업데이트와 다른 문제다.

5. 공백 비율의 분모 효과를 같은 32초 실제 궤적의 8/16/32초 절단 평가로 계산한다. 공백 초, 구역-시간 초, 위험 가중 공백/분모를 모두 기록한다. 재학습 비교는 32초로 고정한다. 짧은 창에 아직 발생하지 않은 작업이 있으면 성공률 우열에 사용하지 않는다.

6. 변경은 에피소드별 고정 슬롯 순열 증강 하나로 제한한다. 기존 4대 최종 checkpoint에서 같은 예산의 identity 재학습과 순열 증강 재학습을 비교한다. 학습 시드7 하나, 각 8,192스텝 상한, Validation은 2,048스텝마다 결정적·확률적 모두 평가한다. 선택은 두 모드 중 낮은 작업 성공률 → 평균 성공률 → 공백 → 제한 응답시간 순이다. 동일 초기 가중치/optimizer 상태에서 시작한다. 보상/학습률/네트워크/PPO 설정을 바꾸지 않는다. 개선하지 않으면 학습량을 추가하지 않고 실패를 보고한다.

새 Training/Validation은 사용하지 않은 사건 시드 구간으로 생성한다. 새 holdout은 별도 파일에 ID·설정·해시만 준비하고 평가 함수와 학습 풀에서 거부한다. 이번 진단 결과로 개발 선택을 한 뒤 그 집합을 미사용 Test라고 부르지 않는다.
