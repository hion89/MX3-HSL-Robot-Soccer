# Phase 4C 원인 분리와 연구 방향 결정 규약 · 2026-11-20

이번 단계는 기존 연구·로봇 코드와 로컬 로그의 읽기 전용 조사, 최소 비학습 진단, 최종 방향 권고다. 새 학습 구조·재학습·설치·원격·실물·Git·외부 전송을 하지 않는다. 신규 파일은 research/cah_mappo 내부에만 생성하고 기존 결과는 보존한다.

## 사전 원칙

최종 결정은 CAH-MAPPO 진행, 정보 문제 중심으로 주제 수정, 기존 방법의 실증 비교로 범위 변경 중 하나다. 미확인이라고만 반복하지 않고 확인된 증거와 필요한 최소 준비를 붙여 권고한다. 신규성은 로컬 코드·자료 검토로 확정할 수 없으며 별도 문헌 검증 전에는 주장하지 않는다.

실패의 단위는 Phase4B의 Native9개와 원래 센서 피드백을 쓰는 기존5모델의 정책-에피소드다. 초기 active-only 투영은 중복 집계하지 않는다. 임무 실패(작업 또는 위협 실패)와 단순 CGR 양수를 구분한다. 원인 A는 증명된 물리 하한, B는 확인된 정보 제약, C는 같은 정보/행동으로 성공한 실행 증인, D는 검증된 평가/인터페이스 문제다. 가능한 정황과 확정 원인은 분리하고 복수 원인·미확정을 허용한다. 제한된 탐색 실패를 A라고 부르지 않는다.

## 최소 실험

- 모든120개 기존 세계에 공개 정보만 쓰는 제한된 위험 방향 예비 인계 진단과 같은146차원·10행동 로컬 규칙을 적용한다. 기존 실패 사례만 골라 성능 우위를 주장하지 않는다.
- 4대 A_near/B/D/고장 계열은 제한된 오프라인 작업 담당자·준비·출발 순서를 탐색한다. 미래를 아는 계획은 가능성 증인이지 실행 기준선이나 완전 시간 최적해가 아니다.
- 기존108쌍에서 전체 사용 가능한 관측 이력과 정책 요청·메타데이터를 비교한다. 기존 Actor5개에도 공통 정책 난수로 두 미래 분기를 재현해 실제146차원 입력·마스크·확률의 prefix 동일성을 확인한다.
- 충분한 미래 분기 정보를 주는 별도 oracle 진단을 수행한다. 실제 센서 단서가 있다고 가정하지 않는다. 같은 물리 조건·행동 제약에서 정보만 달라지는 대조다.
- 속도 배율 .4/.2, 회전 제한1/.5 rad/s, 작업·위협 정보 전달1초 지연을 한 항목씩 바꾼다. 코드의 명령 제한을 이상적으로 추종한다고 가정하는 민감도이며 실측 보정이 아니다. 위치·사건·마감·작업시간은 원래 값 그대로 둔다.
- .125/.0625초 물리 dt에서 대표적인24세계의 사건과 지표를 비교한다. 판단 주기는1초로 유지한다.

로봇 조사에서는 설정 제한·학습 명령 범위·추론 시간·센서 갱신·정지 추정 변동·절대 정확도·실제 이동 성능을 별도 종류로 기록한다. 실제 네트워크 지연과 송신 주기, 실패한 복구 시도와 성공 복구 시간을 혼동하지 않는다. 미측정은 빈 값으로 남긴다.

최종 보고는 기존 Phase1~4B의 단계를 요약하고, 사례별 원인/수량·로봇 근거·시간 해상도·세 주제 후보의 검증 가능성을 정리한다. 권고 이후 새 구현/학습을 자동 시작하지 않는다.
