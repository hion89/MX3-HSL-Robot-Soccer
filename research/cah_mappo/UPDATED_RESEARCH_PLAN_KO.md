# 연구계획서: 실물 제약을 반영한 역할 할당 전략 비교

개정일: 2026-11-23. Phase4C 권고 C의 사용자 수용과 Phase5A 승인에 따른 계획 개정이다. 기존 연구 결과·가설·실험 출력·체크포인트를 수정하거나 삭제하지 않는다. 이번 단계의 성과는 자료 조사와 문서화이며 새 실물/학습 성과가 아니다.

## 1. 가제와 핵심 질문

국문: **실제 휴머노이드 로봇의 이동 및 통신 제약을 고려한 다중 로봇 역할 할당 전략의 정량적 비교 연구**

영문: **An Empirical Evaluation of Multi-Robot Role Allocation Strategies under Real-World Humanoid Locomotion and Communication Constraints**

핵심 질문: 실제 로봇의 이동 성능, 위치추정 오차, 팀 통신 지연, 고장 및 복구 특성이 서로 다른 역할 할당 전략의 작업 성공률, 위협 대응 성능, 책임 공백 및 대응시간에 어떤 영향을 미치는가?

특정 알고리즘의 우월성, 새 MARL 구조 또는 CAH-MAPPO의 필요성을 전제하지 않는다. 같은 물리·정보·실행 조건에서 어떤 전략이 충분하고 어떤 실패·비용이 생기는지를 확인한다. 실제 장비로 확인한 범위와 모델 기반 예측 범위를 구분한다.

## 2. 연구 전환 기록과 기존 가설의 한계

기존 목표는 책임 연속성과 인계 시점을 학습하는 CAH-MAPPO의 필요성을 조사하는 것이었다. Phase1~3에서 학습/중재/지표 기반을 마련하고 Standard MAPPO를 학습했지만 다음 증거 때문에 새로운 인계 학습 구조가 필요하다는 가설이 충분히 입증되지 않았다.

- 원래400개 통제 세계는 Fixed도 모두 성공·공백0이었다. 두 guard가 유지되고 worker가 작업을 순서대로 할 수 있어 인계가 필수인 시험이 아니었다.
- 드문 최대24구역-초 공백은 불필요한 guard 이탈·중복 요청 중재·작업 후 미복귀가 결합했다. 선정한67개 공백 사례는 READY 규칙으로 작업 성공과 공백을 함께 개선할 수 있었다. 이것은 사후 진단이며 보편 우위 검증은 아니었다.
- 새 실패에는 이동·용량 하한, 관측 이력이 같은 숨은 미래, 기존 규칙의 보수적 제약과 worker 간섭, 동결 모델의 분포 이동이 섞였다. 정보를 주지 않은 미래를 학습 부족으로 해석할 수 없었다.
- Phase4C 개발4대의 관측 위협·기존 담당자/후임 고장 주요 계열은 작업 담당자를 보호하는 비학습 보완으로 각각6/6 동시 성공했다. 다른 계열 실패와 조용한 구역의 더 큰 공백 비용도 남아 있어 모든 규칙의 충분성을 주장하지는 않는다.
- 이동1m/s/회전πrad/s/즉시 작업·위협 모델은 실물 보정값이 아니었다. 속도와 정보 지연 가정을 바꾸면 성공률이 달라졌다. 실제 보행·위치·통신·성공 복구의 핵심 GT 자료가 없었다.

Phase4C의 최종 권고와 후보별 판단은 별도 문서 [RESEARCH_DIRECTION_DECISION_KO.md](RESEARCH_DIRECTION_DECISION_KO.md)에 보존돼 있다. 본 계획서는 그 결정을 채택한 후속 연구 계획이다. 미확정7세계와 원인 미확정 실패를 해결된 것으로 고치지 않는다. CAH-MAPPO 구현·재학습은 계속 보류한다.

## 3. 세부 연구 질문

RQ1: 명령과 실제 이동·회전·출발/정지·도착시간 차이가 ETA 기반 선택과 책임 인계 비용을 어떻게 바꾸는가? 단일 평균 속도 모델과 조건별 분포 모델의 예측 차이는 얼마인가?

RQ2: 자기위치/공 오차, 관측 age, 네트워크 지연·유실·타 로봇 상태 발견 지연이 다른 전략에 어떤 영향을 주는가? 없는 정보와 잘못된 선택을 분리할 수 있는가?

RQ3: 같은 deadline·capacity·위협 조건에서 Fixed, Greedy, Exact, 규칙 인계, 동결 MAPPO의 작업 성공·책임 공백·응답은 어떤 상충 관계를 보이는가? 준비를 기다리는 규칙이나 예비 배치가 필요 없는 조건도 있는가?

RQ4: 보정 자료와 독립된 실물 trial에서 시뮬레이션이 이동시간·정보 나이·전략 결과를 얼마나 예측하는가? 실패 원인이 물리·정보·의사결정·평가 정의 중 어디에 속하는가?

위 질문은 검증 대상이다. 예를 들어 짧은 마감에서 빠른 전환이 유리할 가능성과 기존 구역 위험이 커질 가능성을 동시에 검토하며 어느 전략의 승리를 사전 결론으로 쓰지 않는다.

## 4. 재사용 자산과 필요한 추가 작업

기존2~4대/capacity1/복수 작업 시뮬레이터, 센서·통신 cache, 146차원 Actor/141차원 Critic/10행동, 원래 sample과 중재 결과 로그, 종료/고장 처리, JSONL 재평가기를 재사용한다. Fixed/Greedy/전수 Exact/규칙 인계와 동결 Standard MAPPO5개 선택 checkpoint가 있다. 상세 경로와 hash는 [자료 목록](PHASE5A_DATA_INVENTORY_KO.md)에 있다.

아직 없는 것은 독립 실물 GT/동기 반복 자료, 실측 기반 파라미터·검증, 실물 HSL 역할과 연구 task 의미의 공통 adapter, 동일 로컬 입력의 Exact/인계 변형과 감사, 연구 MAPPO의 실물 상위 배포 경로다. 실물 보행·킥 PPO ONNX와 전략 MAPPO checkpoint를 같은 학습 파일로 부르지 않는다.

기존 실물 원본 bag2개와 shadow/짧은 인식 콘솔/실패 영상은 주기·소프트웨어 전이·진단 자료다. 움직임·통신·정확도·성공 복구를 보정할 독립 반복 측정으로는 부족하다. 약29~30Hz 검출 배열 수신과 약80.68ms의 임계→PROTECT 기록 차이도 한정된 부분 측정이다.

## 5. 연구 방법과 단계

**Phase5A — 이번 완료 범위.** 기존 자료를 실물 측정/코드 설정/시뮬레이션/미측정으로 구분하고 GT·시각·반복·중단 조건을 포함한 계측/보정/비교 계획을 작성한다. 모터/launch/서버/새 코드·학습은 실행하지 않는다.

**Phase5B — 별도 승인할 계측.** 한 대에서 P0 시각·기록·GT, P1 선속도/정지, P2 회전, P3 목표 도달, P4 인식·자기위치를 순서대로 수행한다. 정지 네트워크 endpoint를 먼저 확인한 뒤 두 로봇 P5를 준비한다. 기상 P6·킥 점유 P7은 장비 담당자의 별도 승인이다. 각 수집 단계에서 실제 장비·열/전압·저장·계측 실패를 검토해 다음 단계 범위를 정한다.

**Phase5C — 별도 승인할 보정/인터페이스.** 시간·지도·입력·행동·서비스 의미를 연결하고 `empirical_mx3_v1`의 파라미터와 불확실성을 적합/독립 검증한다. 과거 결과는 그대로 두고 새 설정·로그 버전을 만든다. 정보 감사, slot/mask, 중재, 지표재계산을 검증한다. 물리 정확도가 부족하면 전략 비교로 넘어가지 않는다.

**Phase5D — 별도 승인할 전략 비교.** 같은 세계/정보/실행 계약에서 기존 규칙과 동결 MAPPO를 평가한다. local/수신 팀 정보/특권 참고를 분리한다. 학습 분포 밖 전이 실패를 학습 알고리즘의 일반적 한계로 부르지 않는다. 재학습이 필요하면 목표·환경·보상·예산·평가 seed·선택 기준을 다시 승인받는다. 새로운 MARL 알고리즘은 계획하지 않는다.

**제한 실물 비교 — 이후 조건부 단계.** 보정 검증과 공통 task/실행 adapter, 안전·통신 승인 후 두 대의 contact 없는 협력 과제부터 검증한다.4대 비교는 장비/정책별 시험 비용과 공간·통신이 준비된 뒤 별도로 계획한다. 현재 한 대 이력으로4대 또는4대4 실증을 완료했다고 하지 않는다.

## 6. 비교의 공정성과 통계

모든 방법에 같은 물리 파라미터·task/deadline·초기 상태·외생 사건·통신/센서 모델·평가창과 하위 동작/안전 gate를 적용한다. 관측/전달은 각 궤적에서 실제 가능성에 따라 달라질 수 있다. 정책 RNG와 사건 RNG는 분리한다. GT/미래가 Actor나 local 규칙에 들어가지 않도록 실제 입력과 provenance를 기록한다.

현재 로컬146/10 비교는 Fixed/ETA/MAPPO가 준비돼 있고 중앙 Exact/인계를 같은 정보로 간주할 수 없다. Local 변형을 만들고 감사하기 전에는 다른 정보의 참고군으로 보고한다. 준비 행동/ACK와 hidden 진행상태를 어느 방법에만 추가하면 별도 조건으로 둔다. MAPPO inference에는 Critic을 쓰지 않는다.

핵심 결과는 작업 성공/마감 준수, 위협 통과, 응답 가능성/지점 서비스·소유권 공백, 응답/완료시간, 역할 전환, 고장 후 서비스 복귀다. 실제 대응 가능성은 실물에서도 보정 모델을 쓰는 반사실적 ETA 추정임을 명시하고 실제 GT 도달/위협 사건과 대조한다. 위협 통과를 실제 실점률로 부르지 않는다. 단일 가중 종합점수로 우열을 정하지 않는다.

실물 통계의 단위는 trial/session/robot이다. 예비3~5회는 본 측정 충분성 근거가 아니다. 분산/세션 효과·GT 오차·의미 있는 차이와 예산을 확인해 본 반복 수를 고정한다.5개 MAPPO 학습 seed를 독립 학습 반복으로, 여러 episode/sampling은 내부 반복으로 처리한다. 성공 조건부 시간뿐 아니라 무응답·실패·검열·안전 중단을 보고한다. 구체적인 관측/지표/검정 규칙은 [비교 설계](PHASE5A_EXPERIMENT_DESIGN_KO.md)를 따른다.

## 7. 기여 후보와 검증에 필요한 증거

1. **실물 제약 기반 협력 전략 평가 환경.** 계측된 이동·관측·통신·복구 모델과 독립 예측 검증이 있어야 기여로 주장할 수 있다. 현재는 보정 계획과 기존 추상 구현이다.
2. **규칙과 MAPPO의 성능·실패 유형 비교.** 동일 정보·실행 조건, 사전 평가 기준, seed/세션 불확실성과 실패 원인 검사가 필요하다. 전이가 다른 모델을 단순 순위로 나열해서는 부족하다.
3. **제약에 따른 민감도 분석.** 실제 조건의 분포/유효 범위, 물리 요인과 정보 요인의 분리, 제한 상호작용이 필요하다. 임의 숫자를 바꾼 sim 결과만으로 실물 강건성을 주장하지 않는다.
4. **시뮬레이션과 실물 차이의 분석.** 보정과 독립 실물 검증 자료, 시간·좌표·task 대응과 측정 불확실성이 필요하다. 보정 데이터 재현만으로 전이 성공을 주장하지 않는다.
5. **어떤 조건에서 어떤 전략이 충분한지의 정량 근거.** Fixed로 충분한 상황·규칙 비용·MAPPO 전이/재학습의 범위를 모두 보고할 수 있어야 한다. 우위가 없으면 같은 결과/제약/계산·통신 비용도 연구 대상이다.

이 다섯 항목은 아직 확정된 논문 성과가 아닌 **기여 후보**다. 일부 차이가 작다면 동등성 검증에 필요한 사전 한계/검정력까지 따로 준비해야 한다.

## 8. 문헌과 신규성 검토 상태

로컬 `MAPPO_CONNECTION_REVIEW_KO.md`와 Phase3A의 공식 구현 검토 기록에는 marlbenchmark/on-policy의 경로/blob SHA 대조가 있다. B-Human 방식 소스·기존 운영 기록도 참고 자산이다. 이들은 구현 출처/구조 확인이며 새 실증 연구의 신규성을 검증한 문헌 조사와 다르다.

이번 단계는 외부 전송 없이 로컬 자료만 검토했고 최신 공식 논문 검색은 하지 않았다. 따라서 “최초”, “새로운 알고리즘”, “기존 연구보다 우수”를 주장하지 않는다. 다음 문헌 검토에서 휴머노이드 축구 역할 배치, 부분 관측/통신 제약의 작업 할당, sim-to-real 전략 평가, 실측 uncertainty를 반영한 benchmark를 primary paper/공식 supplement로 확인해야 한다. 로봇 대수/기종, 정보 계약, 실제 측정 여부, 비교군, 실패/통계 처리와 데이터 공개 범위를 기준으로 차별성과 중복을 조사한다.

문헌에서 동일 실증 질문이 충분히 해결됐거나 장비로 구별할 효과가 없으면 기여를 더 좁히거나 중단을 검토한다. 알고리즘 이름만 바꿔 신규성을 만드는 방향은 택하지 않는다.

## 9. 최종 평가 데이터와 보존

기존 보호 Holdout400개는 내용·ID·seed를 열람하지 않고 그대로 보존한다. 기존에 분석한400 benchmark/개발120은 개발/진단 자산이다. 실측 분포가 바뀌면 오래된 Holdout의 대표성이 자동 보장되지 않는다. 생성 계약 수준에서만 검토하고 새 조건의 대표성이 필요하면 별도 final set을 보정·정책·입력/행동·평가 규칙 고정 후 만든다.

실물 예비/보정 적합/모델 선택/독립 물리 검증/전략 Validation/최종 평가의 용도를 분리한다. 최종 결과를 본 뒤 수정하면 그 평가를 개발 자료로 표시하고 새 미사용 평가를 준비한다. 원시 실패·중단·검열 자료를 지우지 않는다. 버전/hash/장비·모델 조건과 시각 오차를 남기고 외부 공개는 별도 승인/권리 확인 후 결정한다.

## 10. 장비·위험·현재 한계

과거 확인한 실물 대상은 robo04 한 대다. 현재 사용 가능한 추가 로봇·GT 카메라/모션캡처·기록 PC·무선 동기 장비·정확한 모터/배터리 안전 사양은 확인해야 한다. 첫 이동 측정에는 한 대, 독립 GT와 시각 연결, 안전 구획·받침, 조작자와 안전 담당자2명이 필요하다. 통신의 첫 endpoint 시험은 로봇+PC로 할 수 있지만 두 로봇 실증을 대체하지 않는다.

주요 위험은 잔디/발바닥·배터리·온도에 따른 성능 변화, GT/시각 오류, 기록 부하, 공통 topic 혼선, 작업 정의의 sim/real 불일치, 희귀한 복구 성공 표본 부족이다. 독립 GT가 없으면 정확도/지연 핵심 주장을 제한한다. 실제 협력 장비가 부족하면 보정 시뮬레이션+한 대 동작 검증까지 범위를 줄이고 다중 로봇 실증을 미래 작업으로 명시한다.

## 11. 사용자가 준비할 사항: 우선순위

1. **장비·안전 확인:** 사용 가능한 로봇 수/담당자, 충전 배터리·여분, 실제 모터/배터리 모델의 허용 수치, 물리 정지/토크 해제와 받침 절차, 안전 담당자. 현재 로봇의 전원·토크 상태를 이 문서가 보증하지 않는다.
2. **독립 GT와 시간 연결:** 고정 외부 카메라/모션캡처 또는 제한 끝점 측정 장비, 몸통 표식·기준자·측량점, 시각 동기 표식. 이 준비 전에는 자기위치만으로 실제 속도/정확도를 측정하지 않는다.
3. **안전한 시험 공간:** 연습장 규격/바닥 상태/시작·중단 경계, 카메라 시야, 케이블 동선·완충/지지 장비. 운영 고정 init_pose와 교정 위치를 구분한다.
4. **기준 실행 상태:** 현재 설치된 모델 hash, 러너 variant, 실효 launch/mux/gait/drift/filter/cap을 확인할 준비. 최신 킥 후보나 학습 서버 상태를 모르는 채 기본값으로 단정하지 않는다.
5. **기록과 예비 세션:** bag/CSV/영상/GT 저장 공간, trial 조건표·건강/중단 기록, 시계/QoS·부하 확인. P0를 먼저 승인하고 P1→P2→P3의 한 대 예비를 작은 블록으로 진행한다.
6. **두 endpoint와 이후 두 로봇:** 동일 실험망/고유 선수 번호/clock 방법/수신 capture 준비. 계측 hook·네트워크/ROS 격리 변경이 필요하면 구체적으로 별도 승인한다.
7. **기상·킥은 마지막:** 앞 단계 결과와 안전 절차 검토 후에만 P6/P7 범위를 별도 승인한다. 보행 예비 승인에 자연 낙상·기상·자동 킥·4대 경기가 포함되는 것은 아니다.

측정 실행 절차·중단 조건은 [프로토콜](PHASE5A_MEASUREMENT_PROTOCOL_KO.md), 항목별 보정과 독립 검증은 [보정 계획](PHASE5A_SIM_CALIBRATION_PLAN_KO.md)에 있다. 이 문서 제출 뒤 로봇 실험·새 코드·재학습은 자동 시작하지 않는다.
