# Phase 5B-1 전 확인표 — 아직 실물 측정 미시작

현재 상태는 **오프라인 분석·수집 규격 준비 완료, 로봇 이동 측정 착수 보류**다. ROS 수동 구독 코드도 실물 환경에서 실행/부하 검증하지 않았다. 아래 항목과 사용자의 다음 승인 없이 START/토크/이동·회전·킥·기상을 실행하지 않는다.

## 장비와 안전 담당자

- [ ] 사용할 로봇 ID와 정확한 모터/배터리 모델·셀 구성·충전 상태 확인. 과거 robo04 한 대 이력과 현재 가용성을 구분한다.
- [ ] 제조사/장비 담당자가 확인한 온도·전압·전류 중단 수치와 출처를 manifest에 작성한다. 관측된33~46°C/11.6~12.0V나 명령 cap을 안전 허용 범위로 쓰지 않는다.
- [ ] 균형/발 미끄러짐/센서·GT·동기 유실의 중단 조건과 담당자 판단 절차를 확정한다.45도 FSM 감지값은 사람의 개입을 기다리는 안전 기준이 아니다.
- [ ] 조작자와 안전 담당자 각1명, 물리 지지/완충·추락 방지·전원/STOP 위치 확인. 지지 없이 토크 OFF로 세워 두려 하지 않는다.
- [ ] 정지 절차 검토: 기존 운영 매뉴얼의 역할 정지→로봇 지지→물리 STOP/토크 해제 확인→실행 종료. 비상 시에는 현장 장비 절차가 우선이다. 이 문서에서는 명령을 실행하지 않는다.
- [ ] 모터/배터리 교체·열 상승·이상 전류·hw_error·잔디 걸림·사람 진입·경계 접근·예상 밖 동작이면 즉시 중단하고 자동 반복을 하지 않는다.

로컬 Word 운영 매뉴얼에는 지지한 상태의 STOP/START와 종료 순서가 있다. motor_gains.yaml에는 전류/열 주의, 과거 운영 기록에는 과열 우려로 종료한 이력이 있다. 정확한 기종·배터리의 검증된 수치 안전 범위는 확보하지 못했다. 제조사 수치를 임의로 찾아 일반 모델에 적용하거나 소프트웨어 timeout을 물리 안전 기준으로 만들지 않았다.

## 독립 GT·시각·기록

- [ ] 외부 고정 카메라/모션캡처 또는 제한된 독립 끝점 기준, 몸통 표식·거리 기준·교정 이력·좌표 등록을 준비한다. 자체 pose/odom은 독립 GT가 아니다.
- [ ] 표식 높이/바닥 투영·카메라 왜곡·공 중심·GT 정확도를 검증한다. 시각 marker와 clock offset/drift/잔여 오차를 측정한다.
- [ ] 로봇/기록 PC/GT 장치 clock ID, timestamp 의미, 동기 유효 구간과 오차를 기록한다. 동기 미확인이면 cross-clock 지연은 결측으로 둔다.
- [ ] 실제 설치된 모델 hash/runner/gait/mux/correction/필터/실효 제한·임계값 확인. 로컬 launch 기본값이나 오래된 운영 기록만으로 대체하지 않는다.
- [ ] raw bag/영상/GT 원본 보존 위치, 충분한 저장 공간·source hash·trial ID·조건/반복 번호·비상 중단 기록 준비.
- [ ] collector/ROS custom message/QoS/구독·기록 부하와 raw recorder를 비구동 상태에서 검증한다. 수동 JSONL recorder는 raw image/모든 CDR packet을 원형 보관하는 rosbag 대체품이 아니다.
- [ ] `/tf_static` transient-local, 실제 source/header 시각, 카메라 source frame/검출/추적 주기와 단위 확인. 같은 `/joint_goals` topic의 혼합 관절 이름 stream을 구분한다.
- [ ] 추후 여러 로봇은 ROS domain/namespace/frame 및 팀·선수 번호 충돌을 막는다. LOCALHOST 설정을 임의로 풀어 다른 로봇 명령을 섞지 않는다.

## 승인받을 단일 로봇 순서

1. **P0:** 기록 PC/독립 기준/동기 점검과 안전 지지·비구동 상태의 센서 기록. 원본·봉인·재생성 검사를 먼저 한다.
2. **P1:** 별도 승인 후 한 대의 중앙 안전 통로 직선/정지. 실효 제한 안의 작은 조건에서 출발·정지·GT 속도와 열/전압을 확인한다. 조건별 예비5회는 통계적 충분성 근거가 아니다.
3. **P2:** P1 검토 뒤 회전/정지. 방향·회전율·지연·drift를 분리한다.
4. **P3:** GT 기준 목표 도달/정지 유지와 코드 arrived 시각을 별도 측정한다. 상태·목표 trace가 부족하면 내부 지연을 결측으로 남긴다.
5. 각 trial 원본 보존→검증→봉인→재분석→휴식/건강 확인 후 다음 반복을 판단한다. 본 측정 횟수는 예비 변동·오차·세션 효과·장비 비용을 보고 확정한다.

실험용 시작 예(-0.75,0,0)는 교정 계획의 후보이며 기존 경기 운영 시작(-1.95,+0.8675,0)을 수정한 것이 아니다. 실제 배치와 초기값을 맞추기 전에는 어느 init_pose도 발행하지 않는다.

통신 P5는 모터를 움직이지 않는 로봇+PC endpoint 확인부터, 두 로봇은 장비 준비 후 별도로 승인받는다. 기상/자연 낙상/킥/4대 경기는 이번 준비나 P1 승인에 포함하지 않는다. 상세 조건·안전·반복·불확실성은 기존 `PHASE5A_MEASUREMENT_PROTOCOL_KO.md`를 유지한다.
