2026-11-18. 모든 수치는 실제 코드 실행값이다. 기존 소스·체크포인트·출력은 보존했다. 기존 Python3.12.14 / PyTorch2.7.0+cpu / NumPy1.26.4 가상환경과 CPU만 사용했다. 새 구조, CAH-MAPPO, 새 설치·원격 접속·실물 구동·커밋·푸시는 없다.

## 판단

**기존 MLP와 행동 공간으로 정상 정보 전달 조건의 4대·3작업을 학습할 수 있었다.** 그러나 제한 관측·통신·속도 차이까지 안정화됐다고 판단하지 않는다. 전체 본학습을 즉시 시작하는 판단은 보류한다. 정상 전달 조건의 Standard 기준선은 다음 제한된 검증으로 확장할 수 있지만, 실제 정보 조건은 추가로 고정해야 한다. 최종 holdout은 평가하지 않았다.

## 가설과 실험 통제

결과를 보기 전에 `PHASE3B2A_REPAIR_HYPOTHESES_KO.md`를 작성했다. 슬롯 연결 오류/학습 편향, 물리 작업 불가능성, 정보 부재/선택 실패, 확률 분포 안정성, 공백 분모 효과를 분리했다.

평가 사다리는 고정4대·3작업 → 같은 물리 조건의 슬롯6순열 → 제한 위치 변화 → 우선순위·마감 변화다. 기본 일정은 작업 발생2/4/6초, 필요 수행2초, 평가32초, 책임 구역2개 상시 활성이다. 제한 위치 변화는 기본 좌표에서 ±0.25m 이내이며 구역 담당 초기 오차는 ±0.05m다. 우선순위·마감 조건은 우선순위1/2/4와 기한20/24/28초를 바꾼다. 비교 모델 사이에는 항상 같은 시나리오·슬롯·평가 난수를 사용했다.

재학습 두 설정은 같은 C 최종 가중치와 Adam 상태에서 시작했다. 각각8,192스텝, 학습 시드7 하나, 같은 Training 12개다. 차이는 에피소드별 고정 슬롯 순열 증강뿐이다. 보상·학습률·네트워크·PPO는 바꾸지 않았다. 모델 선택은 두 평가 모드를 모두 사용하는 새 Validation 규칙으로 고정했다. 기존 실험과 이 규칙 변경을 혼동하지 않도록 별도 결과로 저장했다.

## 1. 작업 가능성과 슬롯 편향

Exact는 고정1개, 위치 변화4개, 우선순위·마감 변화4개, 총9개 물리 시나리오에서 모두 작업3개를 완료했다. 따라서 이 진단 범위에서 task2 자체가 기한·이동·용량 때문에 불가능한 것은 아니다.

기존 C 신경망을 같은 고정 물리 환경에서 평가했다. 순열은 표시 슬롯2/3/4가 어떤 기존 논리 슬롯을 가리키는지다.

- `(2,3,4)`와 `(3,2,4)`: task0·task1 완료, task2는 알려졌지만 선택하지 않음.
- `(2,4,3)`와 `(4,2,3)`: task0·task2 완료, task1을 선택하지 않음.
- `(3,4,2)`와 `(4,3,2)`: task1·task2 완료, task0를 선택하지 않음.

결정적 전체 성공률은 모든 순열에서66.67%였지만 **실패하는 실제 작업이 슬롯에 따라 바뀌었다.** 표시 슬롯4/행동6에 놓인 작업을 놓쳤다. 작업 ID·위치·발생·마감·우선순위는 같았다. 같은 물리 행동을 강제로 양방향 변환해 실행하면32초 전체 상태·보상·평가 지표가 정확히 같았다. 따라서 ID 변환 오류보다 학습한 슬롯 편향을 뒷받침한다.

같은 고정 조건의 기존 확률적 정책은 순열에 따라 성공률0~66.67%, 평균38.89%였다. 인덱스를 정확히 연결하는 것과 신경망이 슬롯 변화에 강인한 것은 별개다.

## 3. 학습 과정과 확률 변화

두 설정 모두 최종8,192스텝 checkpoint가 Validation에서 선택됐다. Validation은 물리 시나리오2개 × 순열6개 × 두 모드다. identity는4,096스텝부터 두 모드 성공100%, 증강은8,192스텝에 두 모드100%였다.

- identity: 첫/마지막 rollout Return -3.60371→3.43984, 마지막 entropy0.54927, Actor loss -0.002435, Critic loss0.07143.
- 증강: Return -3.98105→3.13232, 마지막 entropy0.58623, Actor loss -0.001326, Critic loss0.11052.
- update 보고의 approximate KL 최대는 identity0.005483, 증강0.003819; clip fraction 최대는0.07324, 0.03027이었다.
- 같은 rollout에서 PPO 업데이트 전후 전체 분포를 직접 비교한 최대 KL은0.02974, 0.02508; 행동 확률의 최대 절댓값 변화는0.11135, 0.10774였다. 한 번의 PPO 업데이트는4 epochs 전체를 뜻한다.
- Critic의 clip 전 norm은 일부 컸지만 clip 후 제한0.5를 지켰다. 모든 사전 업데이트 log-probability 오차는0이고 NaN/Inf는 관측되지 않았다. 현재 진단에서 확률 폭주가 미완료의 주원인이라는 증거는 없다.

훈련 중 task0/task1/task2 선택 요청은 identity에서5,682/2,765/2,588회, 증강에서4,347/3,904/3,887회였다. 증강이 요청을 더 균등하게 만들었지만 이것은 완료 횟수 자체가 아니다. 모든 단계의 작업 ID·표시 슬롯·엔진 행동·mask·샘플 확률·중재 결과를 평가 raw와 훈련 재생 로그에서 확인할 수 있다.

## 4. 3대 결정적·확률적 차이

기존과 같은12개 B3 개발 시나리오와 평가 난수로 재현했다.

- 초기1,024 checkpoint: 결정적100%, 확률적54.17%. 결정적 궤적의 평균 entropy1.0533/최대 행동확률0.4370, 확률적 궤적의 평균 역할 변경13.58회.
- 최종4,096 checkpoint: 결정적100%, 확률적91.67%. 결정적 궤적 entropy0.6996/최대 확률0.6933, 확률적 역할 변경4회.

서로 다른 궤적의 entropy이므로 이것만으로 인과를 단정하지 않았다. 추가로 같은 초기 신경망·시나리오·샘플 RNG에서 **평가 온도만1→0.5**로 낮췄다. 성공률은54.17→45.83%, 역할 변경13.58→11.17회였다. 확률 분포를 더 뾰족하게 하는 것만으로 해결되지 않았다. 이 추가 진단은 가중치 갱신0회이며 모델 선택에 사용하지 않았다.

작업 수행에는 연속적인 이동·서비스 유지가 필요한데 확률적 요청 전환과 중복 중재가 이를 끊을 수 있다. 확률적 분포의 안정성과 작업별 실행 궤적을 함께 확인해야 한다. 새로운 유지 제어기나 RNN을 넣어 해결했다고 보고하지 않는다.

## 5. 작업 정보 부재와 선택 실패

D 물리 시나리오6개, 총18작업을 같은 고장·감속·위험도 일정으로 평가했다. 정보 전달만 controlled/zero_delay/realistic으로 구분했다.

기존 C의 결정적 평가:

- 정상 전달: 성공12/18=66.67%; 정보 부재0; 알려졌지만 미선택6/18=33.33%.
- 실제 조건: 성공8/18=44.44%; 기한 내 정보 부재6/18=33.33%; 알려졌지만 미선택3/18=16.67%; 선택 후 미대응1/18.

identity 재학습:

- 정상 전달: 결정적·확률적 모두18/18=100%.
- 동일 센서/잡음에 지연0: 두 모드 모두11/18=61.11%.
- 실제 지연2초: 두 모드 모두10/18=55.56%. 기한 내 정보 부재6/18=33.33%, 알려졌지만 미선택0, 선택했으나 대응하지 못한 작업2/18=11.11%였다.

같은 물리 조건에서 정상 정보 전달이면18개를 완료하므로, 제한 정보 조건의 실패 전부를 할당 학습 능력 부족으로 볼 수 없다. 그러나 전체 임무 성공률에서는 미관측6개도 그대로 실패로 포함했다.

증강 모델은 D 정상 전달에서 결정적50%, 확률적100%, 실제 조건에서 결정적38.89%, 확률적50%였다. 슬롯 증강만으로 속도·위험·관측 조건의 분포 변화까지 해결되지 않았다. 정상 전달 조건은 peer 관측도 개선하므로 모든 차이를 작업 메시지 하나의 효과로 해석하지 않는다. 지연만의 효과는 zero_delay와 realistic을 비교한다.

모든 작업의 발생, 로봇별 센서/수신/인지/선택/수락, 대응·완료·만료를 저장했다. 수신 로그에서 측정 시각과 도착 시각을 구분했고 실제 지연 전에는 Actor에 전달되지 않음을 테스트했다. ‘알려졌지만 미선택’은 **기한 내 선택 없음**을 뜻한다. 선택 후 중재·도달·고장·마감으로 실패한 범주와 구분한다.

## 6. 평가 시간과 공백 분모

같은 기존 C 결정적 궤적을 절단했다. 구역 우선순위는 각각1로 고정되어 위험 가중 값과 구역-초가 같다.

- 8초 창: 공백6 구역-초 / 평가 구역16 구역-초 =37.5%.
- 16초 창: 공백13 / 평가 구역32 =40.625%.
- 32초 창: 공백13 / 평가 구역64 =20.3125%.

16초 이후 새로운 공백이 없으면 실제 공백13초가 그대로여도 비율은 절반으로 줄어든다. 따라서 주 비교는32초로 고정하고 실제 공백 구역-초·구역 시간·위험 가중 분모를 함께 보고한다. 8/16초 창으로 작업 성공률 우열을 판정하지 않는다. 구역2개가 동시에 비는1초는 공백 구역-초2다.

## 7. 실행·테스트·감사

- 원래 학습: 두 설정 각8,192, 총16,384 고유 환경 스텝. 중간 Validation 포함 시간82.866초·82.789초. 최초 Validation과 개발 평가 시간은 제외했다.

새 최종 holdout은 위치 변화200개와 우선순위·마감 변화200개, 총400개의 **설정·ID·해시만** 준비했다. 결과는0개다. 환경과 학습기가 해당 split을 거부한다. 이미 사용한 예전 Test와 이번 개발 사례는 최종 미사용 평가 집합이 아니다. 이후 설정·선택 규칙·모델을 동결하고 별도 승인 후 평가 경로를 열어야 한다. D의 최종 조건은 정보 전달 규칙을 정한 뒤 별도로 준비해야 한다.

## 9. 본학습 시작 판단

정상 정보 전달·제한 위치 분포에서는 기존 구조로4대·3작업을 완료할 수 있다는 최소 근거를 확보했다. 하지만 단일 학습 시드와 적은 물리 시나리오의 결과다. 슬롯 증강도 확률적97.22%와 D 전이 실패가 남았으므로 전체 문제가 해결됐다고 보고하지 않는다.

전체 Phase 3B-2B는 아직 보류하는 것이 타당하다. 필요한 조건은 다음과 같다.

1. 주 운용 모드와 두 모드 Validation 선택 규칙 고정.
2. D에서 실제로 발견할 경로가 없는 작업을 스트레스 사례로 분리하거나, 발생 후 모든 정책에 동일하게 전달되는 작업 통지/공통 탐색 규칙 명시. 미래 GT를 Actor에 주지 않는다.
3. 슬롯 증강의 효과를 더 넓은 Validation과 독립 학습 시드에서 확인. 신경망·보상·학습률을 함께 바꾸지 않는다.
4. 같은32초 창과 위험 계산, 전체 성공률과 조건부 실패 분류를 공통 평가 규약으로 유지.
5. 정확한 중간 resume와 장시간 실행 재현성 보완 후, 최소5개 독립 학습 시드와 시드별 계열당200개 평가의 예산 확정.

CAH-MAPPO나 대규모 다중 시드 학습은 시작하지 않았다. 이 보완 단계는 종료하고 다음 승인을 기다린다.
