## 동일 평가 조건의 정책 비교

다음은 각 정책당 20 에피소드의 실제 평균이다. 응답시간은 **대응 시작 이벤트가 기록된 작업만**의 평균이다. 미응답 작업을 시간 0으로 처리하지 않는다. 책임 공백 비율은 에피소드가 실제 지속된 구간에 대한 비율이다.

비학습 기준선은 두 학습 시드에서 동일한 결과였다.

## 체크포인트 선택과 남은 불안정성

학습 중에는 학습 환경 시드 100의 결정적 평가로만 디버깅 체크포인트를 선택했다. 성공률을 먼저 보고, 성공률이 같을 때 학습 Return으로 후보를 골랐다. 별도 평가 시드는 선택에 사용하지 않았고, 이 선택 기준으로 논문상 알고리즘 순위를 매기지 않는다.

- 시드 7: `checkpoints/best_step1024.pt`.
- 시드 11: `checkpoints/best_step256.pt`.
- 이 두 후보의 결정적 평가: 성공 100%, 응답시간 8초, 책임 공백 0%, Return 1.48958. B가 먼 작업을 처리하고 A가 구역을 지키는 행동으로 더 느리지만 공백이 없다.
- 동일 후보의 확률적 평가: 시드 7 성공률 85%, 시드 11 성공률 50%. 최종 체크포인트의 확률적 성공률 100%보다 낮다.

즉, 초기에 argmax 한 번으로 잘 작동했다고 해서 전체 확률 분포가 충분히 학습된 것은 아니었다. 보고에서는 최종 checkpoint와 조기 선택 후보를 모두 남겼다. 이 차이와 구역 공백/응답속도의 trade-off는 이후 보상·평가 규칙을 고정하고 검토할 문제다.

## Phase 3B-2를 위한 제안 — 아직 실행하지 않음

의존성은 현 CPU 가상환경만으로 다음 작은 실험을 시작할 수 있다. PettingZoo 공식 API 검증이 필요하면 어댑터용 별도 설치 승인이 필요하며, 현재 환경 자체가 이를 요구하지는 않는다. GPU·CUDA는 현재 27,531 파라미터 모델의 필수 조건이 아니다.

다음 단계는 먼저 종료 규칙과 평가 구간을 확정하고, 최종/최선 정책 선택 규칙과 평가 시드를 사전 고정하는 것이 적절하다. 이후 작업 수, 시작 분포, 관측 제한, 장애·지연을 하나씩 늘려야 한다. CAH의 인계 행동과 Standard의 행동 공간 차이, 보상 차이, 실행 중재 차이가 비교에 섞이지 않도록 실험 설계를 먼저 확정해야 한다.

규모의 출발점 제안은 두 알고리즘 × 학습 시드 5개 × 100,000 환경 스텝 = 총 1,000,000스텝이다. 이는 승인 요청을 위한 잠정 규모이며 이번에 실행하지 않았다. 같은 디버깅 처리율을 단순 환산하면 약 68분이지만, 복수 작업·통신·평가 횟수와 새 알고리즘 비용이 달라지므로 본학습 소요시간 예측으로 사용할 수 없다. 확대된 환경을 짧게 측정한 뒤 예산을 다시 잡아야 한다.

현 PC의 CPU/RAM은 현재 2~4대 2D 환경 및 작은 MLP의 후속 검증에 충분한 출발점이다. GPU 본학습, 서버 접속, 실물 구동, Git 커밋·푸시는 수행하지 않았다. Phase 3B-2는 별도 승인을 기다린다.
