# Phase 4B 사전 규약 · simulator validity v1

목표는 책임 공백과 명시적인 위협 통과의 연결, 사전 배치의 정보 조건, 시간 해상도의 영향을 검증하는 것이다. CAH-MAPPO·재학습·새 신경망은 구현하지 않는다. 기존 파일과 결과를 바꾸지 않고 `phase4b` 코드와 `phase4b_outputs/study_v1`을 추가한다. 기존 보호 Holdout은 내용·ID·시드를 읽지 않는다. 설치·원격·실물·Git 반영·외부 전송을 하지 않는다.

## 보존할 것과 추가할 것

기존 CGR은 그대로 계산하고 `legacy_*` 이름으로 병기한다. 새 버전 `phase4b-coverage-v1`에 명시 담당자 공백, 정해진 응답 예산 안에 도착 가능한 물리 커버 공백, 실제 진행 중 위협의 잔여 도착시간을 고려한 가중 공백, 모든 작업 완료 이후의 공백을 추가한다. 지속 구역 책임은 작업 완료 후에도 종료하지 않는다. 위협이 없을 때 위협 통과율과 위협 가중 분모는 N/A이며 0% 성공으로 채우지 않는다.

상대와 공을 함께 이동하는 점으로 단순화하고, 알려진 구역까지 직선·일정 속도로 이동시킨다. 실제 구역 도달 시점에 가동 중이며 다른 작업을 수행하지 않는 로봇이 구역 반경 안에 있으면 방어 성공, 없으면 `threat_passed`다. 같은 로봇으로 여러 동시 위협을 무제한 막지 못하게 매칭한다. 이 비율을 실점률이라고 부르지 않는다. 속도1/0.45~0.55m/s, 반경.25m, 응답 예산2초 및 모든 상대 이동값은 실측이 아닌 시뮬레이션 가정이다. 실제 연습장·보행/킥 물리를 재현했다는 주장을 하지 않는다.

## 정보와 행동

비학습 정책은 동일한 현재 공개 팀 관측, 현재 활성 작업, 실제 드러난 위협 위치·진행 방향만 받는다. 미래 작업·고장 일정·시나리오 ID·사건 시드는 입력에서 제외한다. 위협 도착 예측은 관측된 위치·속도에서 계산한다. 모든 정책에 구역 준비 중첩 행동을 허용하며, 작업이 나타나기 전의 일반적인 예비 배치도 금지하지 않는다.

기존146차원 MAPPO Actor는 그대로 별도 전이 참고군으로 사용한다. 외부 관측 버스에 새 위협 정보가 있어도 기존 가중치/입력 구조는 이를 처리하지 않는다. 따라서 위협 채널을 사용하는 새 규칙과 동등한 학습 조건의 비교군이라고 부르지 않는다. Critic·미래 정보를 Actor에 전달하지 않는다.

사전 배치는 (1) 관측 위협 기반, (2) 신호 없이 알려진 구역에 미리 보내는 상시 예비 배치, (3) 발생 후 반응, (4) 미래 일정 전체를 아는 오프라인 탐색을 구분한다. (4)는 실행 정책이 아니며 제한된 계획 집합의 가능성 증인이다. 탐색 실패를 불가능성 증명이라고 하지 않는다. 별도의 작업량 하한으로 증명되는 불가능 대조군을 포함한다.

## 세계 집합과 비교

새 개발/Validation 2개, 진단6개를 각10계열×2팀 규모(2/4대)에 생성한다. Phase4A A/B/C의 물리 조건과 절대 마감을 재사용하되 새 생성 버전·인덱스를 쓴다. 새 시간 해상도에서 명목 B/C의 분류가 달라지면 숨기거나 재조정하지 않고 보고한다.

계열은 인계 불필요·위협 없음, 가까운 작업(상시 예비 배치의 비용), 정상 인계, 발생 후 처음 보이는 긴급 위협, 미리 보이는 같은 위협, 기존 담당자 고장, 후임 고장, 새 위협 발생/위험 변화, 작업 후 위협, 작업량 초과의10가지다. 계열 비율은 실전 발생 확률이 아니다. 유리한 사례만 사후 선택하지 않는다.

Fixed, Greedy/ETA, Exact+전환비용, 기존 Handover, READY, 적응 인계, 관측 위협 기반 예비 배치, 상시 예비 배치, 관측 한정 짧은 예측 계획을 비교한다. 추가 Actor 전이는 기존 선택5시드의 결정적/확률적 실행으로 분리한다. 알고리즘 우열의 단일 종합점수는 만들지 않는다.

주 물리 dt=.25초, 판단 주기1초. 민감도는 dt=1/.5/.25/.125초에서 같은 위치·속도·절대 사건/마감·판단 주기를 유지한다. dt=1초로 만든 마감이 유효한지 자체를 검증하며 수치를 유리하게 다시 만들지 않는다.

관측 예비 배치 경고 범위 후보4/8/12초와 짧은 예측 범위2/4/8초는 Validation에서만 선택한다. 기존 Phase4A 적응 인계 임계값 .5/4는 유지한다. 선택은 실제 도착 위협 실패와 활성 작업 기한 초과를 각각 보고한 뒤, 내부 선택에만 명시적인 동수 비용과 성공/지연 tie-break를 사용한다. 이는 정책 내부 및 설정 선택 규칙이며 성능 종합 순위가 아니다. 진단 결과로 재선택하지 않는다.

## 검증

공개 관측의 미래 독립성, 상시/관측/오프라인 정보 구분, ETA 커버와 실제 방어의 차이, 동시 위협의 용량1, 소유권과 물리 커버의 차이, 위협 없는 분모 N/A, 작업 후 책임 지속, 정확히 한 번의 도착 이벤트, dt 변경 시 물리 조건 불변, 로그 단독 지표 재계산과 기존179개 회귀를 검사한다. 주 비교와 계획/해상도 실험은 원시 로그 및 설정을 저장한다. 기존 자료와 선택 checkpoint는 해시로, 보호 파일은 메타데이터만으로 보존한다.
