# Phase 5A 실측 기반 시뮬레이터 보정 계획

2026-11-23. 설계 문서이며 보정·코드 수정·새 실행을 하지 않았다. 기존 Phase1~4C 결과와 checkpoint는 그대로 보존한다. 측정 ID P0~P7은 [측정 프로토콜](PHASE5A_MEASUREMENT_PROTOCOL_KO.md), 자료 등급은 [자료 목록](PHASE5A_DATA_INVENTORY_KO.md)을 따른다.

## 1. 보정 대상과 범위

목표는 기존2D 전략 환경에서 이동·관측·정보 전달·서비스 불가 시간을 실물 자료와 연결하는 것이다. Isaac의 접촉 물리/보행 PPO를 다시 학습하거나 실제 마찰계수를 추정하는 작업이 아니다. 같은 보행·킥 모델이라도 바닥·전압·러너·제어 경로가 달라지면 실효 성능이 달라질 수 있어 그 조건을 parameter set의 일부로 둔다.

현재 연구 자산은 Phase2 capacity1 이동/할당, Phase3A의146/141/10 정보 계약, Phase4B의 별도 물리/제어 시계와 도달 사건 평가다. 실제 HSL의 역할/공 담당 결정과 연구 모델의 task assignment는 같은 API가 아니다. 다음 단계에서 사용할 관측/작업·실행 adapter를 정의해야 하며 현재 이미 연결됐다고 주장하지 않는다.

새 보정 버전의 가칭은 `empirical_mx3_v1`이다. 실제 측정과 검증을 완료하기 전에는 `assumption_only`로 표시한다. 기존 `phase4b-validity-v1`, 개발120개, 기존32초 평가와 모든 가중치를 조용히 바꾸지 않는다. 향후 새 설정에는 장비/바닥/모델·러너 hash/날짜/데이터 split/분포·단위·좌표·유효 범위/불확실성/식별자를 남긴다. 이번에는 그 설정 파일이나 보정 코드를 생성하지 않는다.

## 2. 파라미터별 대응

### C0 지도·기하와 몸체 기준점

- 현재:2D 지점/반경0.25m, 경기장 경계·로봇 footprint·실제 map 등록 없음. Phase4C에서120세계 중108개의 축 정렬 span이 연습장3.9×2.6m를 초과했다.
- 측정: P0/P3/P4의 독립 측량, 몸통 기준점/공 중심, 경기장 선·영역·실제 바닥 외곽. 단위 m/rad, map/body/GT-camera 변환과 uncertainty.
- 보정: 독립 기준점에서 고정 rigid transform을 정하고 실제 도면의 경계·footprint 여유를 새 버전에 명시한다. 연습장/9×6 실전장을 별도 profile로 둔다. 임의 축척으로 기존 결과를 실물 결과로 바꾸지 않는다.
- 검증: 보정에 쓰지 않은 기준점/위치와 역방향 궤적에서 좌표 오차·범위 적합성을 확인한다. 궤적마다 정렬을 다시 맞춰 bias를 지우지 않는다.
- 미확보 시: 기존 추상 좌표만 유지하고 실물 연습장 재현 주장·물리적 대응 거리의 해석을 보류한다.

### C1 조건별 실제 속도·회전

- 현재: guard1m/s, worker0.45~0.55m/s, turn_speedπrad/s의 상수. 실제 제한0.20/0.15/0.50 등은 명령값이며 이 상수를 대체할 실측 GT가 아니다.
- 측정: P1/P2/P3의 requested/shaped/consumed cmd, GT 평면 궤적/yaw, 바닥/전압/온도/정책 조건. GT map 속도를 `v_body = R(−yaw) v_map`으로 변환해 m/s, rad/s로 비교한다.
- 보정: 우선 조건별 명령→실제 속도/ETA lookup과 세션별 오차 분포를 후보로 둔다. 선형·횡·후진·좌우 회전·제자리 회전·선회를 구분한다. 과제의 실제 운용 속도 범위만 식별하고 최고속도로 외삽하지 않는다.
- 검증: 보정에 쓰지 않은 방향/거리/세션에서 도달시간·경로·yaw의 예측 편향과 분포 coverage를 본다. 실제 결과의 순위가 아니라 물리 예측 오차로 모델을 선택한다.
- 미확보 시: 명령 상한을 실속도로 채우지 않는다. 기존 상수는 가정값으로 남기고 별도 민감도 범위만 제시한다.

### C2 출발·정지·회전 전이와 실행 지연

- 현재: 먼저 방향을 돌린 뒤 일정 속도로 이동한다. 가감속·지지발 교대·미끄러짐·명령 경로 지연의 독립 모델이 없다. 실제 WalkToPose는 가까이서 횡이동·동시 회전을 허용한다.
- 측정: P0~P3의 decision→publish→mux→consume→goal publish→GT motion/stop 시각, 속도 step의10~90% 전이·정지 거리. 단위 s, m, rad와 시간 오차.
- 보정: 역할 판단 주기, 메시지 전달, 보행 정책 주기, 기계 반응을 분리한다. 가속 제한/지연+응답 모델/경험적 이동시간 분포를 최소 후보로 비교한다. 흔들림·gait phase 때문에 단일 first-order 모델이 맞지 않으면 구간 모델이나 trial trajectory 재표집을 검토한다.
- 검증: 독립 step/방향 변경/연속 목표에서 onset·stop·overshoot·ETA를 예측한다. timestamp 의미가 확인되지 않은 값으로 분해 지연을 맞추지 않는다. 추론0.29ms를 기계 지연으로 쓰지 않는다.
- 미확보 시: 전체 복합 지연만 확인됐다면 해당 범위의 총 지연으로만 모델링한다. 분해 불가능성을 표시하고 여러 항에 같은 지연을 중복 더하지 않는다.

### C3 자기위치 오차와 공 측정 오차

- 현재: Phase3A 기본 peer/job 센서 잡음은 uniform0.02m, own odometry는 완전값으로 처리된다. Phase3B-2B 실제 학습은 sensor100m/noise0/radio0이었다. Phase4B Native 공개 팀 상태도 이상적 현재 정보다.
- 측정: P4의 독립 GT 대비 몸체 x/y/yaw, 상대 공·지도 공의 잔차, 거리/방위/조명/목·카메라 자세/가림/이동 상태, validity/quality/관측 실패. m/rad, covariance 단위도 명시한다.
- 보정: bias와 random residual을 구분하고 위치·거리·움직임 의존성, 시간 상관·jump·dropout을 추정한다. 독립 Gaussian을 기본 정답으로 두지 않는다. 공의 지도 오차에는 동일한 로봇 pose 오차가 공유되므로 상대 공 잡음과 지도 pose 잡음을 독립으로 두 번 넣지 않는다.
- 검증: 새 위치/trajectory/세션에서 RMSE·p95·bias·invalid/재획득율과 예측 구간의 실제 포함률을 확인한다. 정지 추정 범위나 알고리즘 covariance만으로 noise 분포를 정하지 않는다.
- 미확보 시: 절대 정확도는 미측정으로 남긴다. 제한된 GT 끝점만 있으면 해당 끝점 오차까지만 보정하고 연속 경로/시간 상관을 추정하지 않는다.

### C4 새 관측 주기·지연·정보 신선도

- 현재: 연구 sensor update는 제어 step마다 생성되는 구조다. 실제 검출 배열 약29~30Hz 기록, tracker 기본50Hz, pose30Hz, 보행 주기20ms, 전략20Hz는 서로 다른 단계다. tracker가 현재 시각으로 예측을 발행해도 source 관측은 오래될 수 있다.
- 측정: P0/P4의 취득→검출→TF→tracker→전략/러너 소비 시각, 새 source frame ID, color/depth skew, 실제 구독 표본과 누락. 단위 s/Hz와 각 clock의 의미.
- 보정: source generation/delivery/use를 별도 queue·cache로 표현하고 예측 발행을 새 관측으로 세지 않는다. phase offset·delay tail·dropout burst를 조건별로 반영한다. 검출→TF 대기와 정책 입력 캐시 나이를 겹쳐 더하지 않는다.
- 검증: 독립 moving/occlusion 시퀀스의 source-age 분포·invalid 전환·재획득과 실제 제어에 사용한 표본을 비교한다. 전체 stream Hz만 맞추고 실제 source가 낡은 문제를 놓치지 않는다.
- 미확보 시: timestamp 의미가 알려진 구간의 지연만 보정한다. 나머지는 알려지지 않은 범위로 남기고 경계 민감도를 별도 보고한다.

### C5 팀 통신과 타 로봇 상태 나이

- 현재: Settings 기본 delay2초/cache4초, 본학습은 delay0초. 실제 송신2Hz+event, teammate TTL2초, 20ms polling/100ms 발행이며 packet에는 source timestamp가 없다. 단순 “메시지 지연” 한 개로 같은 모델이라고 볼 수 없다.
- 측정: P5의 matched seq TX/RX, 중복/유실/순서 역전, ROS/전략 use, source sample age, clock 오차, 거리/가림/부하. 단위 s와 손실확률/연속 손실 길이.
- 보정: 송신 스케줄·event token·전달/queue 지연·손실/순서·캐시 TTL·소비 주기를 분리한다. 원래 packet이 운반하지 않는 미래 task 목록·타 로봇 GT를 Actor에 추가하지 않는다. 실제 pose/ball/role 정보에서 어떤 작업 후보를 만들 수 있는지 공통 adapter에서 먼저 정의한다.
- 검증: 독립 세션/예비에 쓰지 않은 경로에서 도착 간격·age·발견 지연·손실 burst의 분포를 예측한다. source stamp가 없으면 pose AoI 전체가 검증됐다고 하지 않는다. 통신량/메시지 크기도 비교 조건에 포함한다.
- 미확보 시:2Hz를500ms 지연으로 변환하지 않는다. 동기 오차가 크면 RTT/수신 간격만 보정할 수 있고 단방향 지연은 구간 또는 미측정으로 남긴다.

### C6 고장·감지·기상·실제 서비스 복귀

- 현재: 외생 failure/recovery event가 operational bool을 시각에 맞춰 바꾼다. 감지/PROTECT/기상 운동/정지 안정/새 명령 수용을 나누지 않는다. 일부 t=10 recovery는 물리 기상 시간 측정이 아니다.
- 측정: 별도 승인된 P6의 GT/상태 전이, 단계별 소요시간·성공/실패·검열, 바닥/배터리/시작 자세. 단위 s/attempt/session, 감지된 상태와 실제 상태를 분리한다.
- 보정: service unavailable 구간과 detect/protect/getup/upright/ready 단계를 분리한 최소 상태 모델을 후속 검토한다. 고장 발생과 관측 전파 지연도 분리한다. 자연 낙상과 인위적 가용성 중단은 다른 조건이다.
- 검증: 별도 시도에서 기상 성공률, down time 분포, ready 신호와 실제 서비스 재개 차이를 확인한다. 실패는 누락하지 않고 복구 미완료는 검열 처리한다.
- 미확보 시: 성공률/시간 분포를 실패 bag 한 개나 timeout으로 채우지 않는다. 외생 가용성 중단을 가정한 진단으로 제한한다. 정책 때문에 넘어지는 내생 실패를 모든 정책에 동일한 외생 사건으로 강제해 차이를 지우지 않는다.

### C7 작업 서비스·용량·인계 READY

- 현재: 알려진 고정점에서2초 또는12초 누적 서비스, capacity1, base 준비 중 중첩 허용. 도착/READY는 반경 기준이며 실물의 방향·균형·명령 소유권 확인을 모두 뜻하지 않는다.
- 측정: P3/P7의 goal GT 도착, 안정 유지, 접근·정렬·hold·실행·사후 복귀, 다음 작업 수용, 실제 공 이동 결과. m/rad/s와 현재 담당·실행 소유권.
- 보정: 단순 영역 방문/유지 과제와 실제 킥 과제를 분리한다. 실제 역할 책임/active player와 연구 task ID의 대응을 정하고 걷기/킥 출력의 중재를 공통 실행 계약으로 둔다. READY는 실제 점유+방향+작업 가능성 확인으로 정의할지 데이터로 검토한다.
- 검증: arrived/done/NORMAL이 난 시점과 독립 GT 성공·다음 동작 가능 시점을 비교한다. soft signal 성공과 물리 성공을 별도 보고한다.
- 미확보 시:12초 점유를 실제 축구 동작 시간으로 부르지 않는다. 킥2.0초와 hold0.6초도 러너의 timer 포함 관계를 확인한 뒤 사용한다. 단순 합산해2.6초로 놓거나 실패 시도를 성공 service로 학습시키지 않는다. 실행 중단 뒤 누적 progress를 이어가는 추상 작업이 실제 과제에 맞는지도 별도 검증한다.

### C8 위협·응답 예산·평가 시간

- 현재: 속도1m/s 직선 공/상대 점, 도달 순간 반경 내 free robot의 자동 방어, 응답 예산2초, 32초 평가. 접촉·중간 가로채기·실점이 없다.
- 측정: P4의 공 궤적, 후속 승인된 안전한 목표/영역 대응 실험의 도달시각·응답·실패. 실제 상대나 공 접촉 방어 성능 자료는 현재 없다.
- 보정: 우선 contact 없는 “위협선/지정 영역 도달 전 응답” 과제를 정의하고 위협 속도/도달 ETA 오차/마감 여유를 실측 또는 명시한 통제 조건으로 둔다. 실제 공 통과/접촉 방어와 ETA 기반 가상 사건은 다른 지표로 남긴다.
- 검증: 새 위협 경로에서 예상 도달시각과 GT 도달을 비교하고, 방어 사건 판정도 독립적으로 점검한다. 실제 실점률이라는 표현을 쓰지 않는다.
- 미확보 시: 기존 점 모델만 유지해 추상 위협 통과율로 보고한다. 연구 결론을 실제 경기 득실점으로 확대하지 않는다.

## 3. 평균과 분포의 선택

평균만의 모델은 기존 상수 속도 기준선과 계산 비용을 비교하는 **축약 모델**로 남긴다. 운영 모델 후보는 바닥·로봇/모델·명령 크기/방향·건강 조건별 분포다. 지연 tail·burst loss·성공/실패·재획득은 평균으로 대체하면 마감과 인계 위험을 지울 수 있어 우선 분포를 보존한다.

작은 예비 표본에서는 세부 조건마다 복잡한 분포를 맞추지 않는다. 표본 수·유효 범위·식별 불확실성을 명시하고 세션/trajectory block 재표집 또는 단순 계층 모델을 후보로 둔다. 데이터가 평균 모델보다 복잡한 모델을 지지하는지는 물리 검증 자료의 예측 오차로 판단한다. 일반화가 확인되지 않은 robot ID/바닥으로 외삽하지 않는다.

전압·온도·센서 신선도와 속도의 상관을 남긴다. 매 tick 독립 노이즈를 새로 뽑으면 실제 느린 drift나 지연 burst가 사라질 수 있으므로 시간 상관을 점검한다. 실측 지면 마찰계수가 없으면 μ를 만들어 넣는 대신 해당 바닥에서 측정한 실효 이동/실패 특성을 우선 사용한다. 전류나 미끄러짐 영상만으로 μ를 확정하지 않는다.

## 4. 자료 분리와 모델 선택

수집 전 session/trial ID로 예비, 보정 적합(C_fit), 후보 선택(C_dev), 독립 물리 검증(C_check)을 나눈다. 연속 영상 frame을 랜덤하게 나누지 않고 날짜/배터리 주기/반복 궤적 단위로 분리한다. 같은 원시 자료의 다른 CSV 사본을 독립 검증으로 세지 않는다. 수량은 예비 분산·측정 비용을 본 뒤 확정한다.

C_fit으로 파라미터를 맞추고 C_dev로 필요한 복잡도를 정한다. C_check를 보고 모델을 수정하면 그 집합은 개발 자료가 됐음을 기록하고 새 독립 검증을 확보한다. 전략 checkpoint/규칙 임계값 선택용 Validation과 최종 정책 Holdout도 별도다. 시뮬레이터 보정에 쓴 실제 궤적을 “sim-to-real 예측 성공”의 최종 증거로 다시 세지 않는다.

독립 검증 항목은 이동/회전/stop/ETA, 위치 잔차·누락·age, packet 지연/손실/상태 발견, 서비스/복구 단계다. bias/MAE/p95, 예측 구간 포함률, 실패/검열 수를 보고한다. 허용 오차는 과제의 마감/도착 허용 오차와 GT 분해능으로 사전 고정하며 어떤 전략이 이겼는지로 보정 성공을 판정하지 않는다.

## 5. 시간 해상도·정보 계약·동일 세계

기존 Config는 사건·서비스·delay가 dt의 배수여야 한다. 실제 연속 지연을0/한 tick으로 반올림해 정보 구조가 바뀌지 않도록, 후속 단계에서 더 세밀한 물리 clock 또는 연속 timestamp delivery queue를 검토한다. Phase4C의0.125/0.0625 비교는1초 제어의 제한96쌍에서만 판정이 같았다.50Hz 정책·20Hz 전략의 정확성을 입증한 결과가 아니다.

공정 비교에서는 물리/센서/통신 사건 스트림과 정책 sampling RNG를 분리한다. 모든 정책에 같은 초기 상태·시간·지연/손실 schedule을 적용하되, 위치에 따라 가시성이 달라지는 실제 센서는 같은 센서 모델을 적용한다는 뜻이지 정책마다 다른 궤적에서도 관측 결과를 강제로 같게 만든다는 뜻은 아니다. 물리 GT는 evaluator/Critic에만 쓰고 Actor/로컬 규칙에는 수신 가능한 결과만 제공한다.

동결 Actor146의 self-state도 현재 perfect own odometry에서 바뀔 수 있다. 새 속도/age/잡음/작업 위치가 학습 범위를 벗어나는 정도, 정규화·slot/mask 연결, 정책 시계의 변화가 초래하는 전이를 기록한다. 입력 크기를 유지했다는 이유만으로 같은 분포라고 판단하지 않는다. 실제 packet이 전달하지 않는 task deadline/priority/ID를 전역 registry에서 몰래 채우지 않는다.

## 6. 보정 완료의 조건과 중단선

실물 GT·시각 오차가 충분히 정의되고, 필수 파라미터가 검증 자료에서 예측 가능하며, 지도/관측/행동/작업 의미가 연결됐을 때만 `empirical_mx3_v1`을 고정한다. 필수 데이터가 없으면 그 축은 가정 또는 미측정으로 남기고 연구 주장 범위를 줄인다. 전략 성능을 높이기 위해 실제보다 빠르게 이동시키거나 정보 지연을 제거하지 않는다.

그 뒤 새 calibrated Validation과 동일 조건 비교를 승인받는다. 기존 보호400개는 그대로 보존하고 열람하지 않는다. 대표성이 다른 경우 새로운 최종 Holdout은 보정/정책/평가 규칙을 모두 고정한 다음 별도 승인으로 만든다. 이번 단계는 계획 문서 작성에서 종료한다.
