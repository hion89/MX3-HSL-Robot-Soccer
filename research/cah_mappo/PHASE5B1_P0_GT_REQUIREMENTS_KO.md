# P0 독립 위치 기준과 시각 동기 준비

현재 검증된 절대 위치 GT는 없다. 기존 자기위치/odom, 공 위치와 사람의 대략적 거리 판단, 킥 영상의 추출 JPEG는 독립적으로 교정·동기화된 궤적 GT가 아니다. 아래는 향후 장비 구성 요구사항이며 실측 결과가 아니다.

## 최소 구성

초기에는 로봇 1대, 조작자·안전 담당자, 모터 비구동 상태를 유지하는 기구적 지지, 고정 외부 카메라, 실제 거리 기준(검증된 자·거리계와 측량점), 몸통에 강체 고정한 추적 표식, 영상 원본·프레임 시각 기록 장치, 공통 시각 단서와 충분한 저장 장치를 준비한다. 모션캡처도 대안이다. 장비의 사양과 실제 검증 오차는 별도로 기록한다.

단일 정면 영상이나 두 바닥 점만으로 전체 이동 중 몸통 2D 위치와 yaw 정확도를 보장하지 못한다. 끝점만 측정할 수 있으면 끝점 오차만 평가하고 가속·지연·순간 속도를 보고하지 않는다.

## 공간 교정

카메라는 삼각대/천장 고정으로 움직이지 않게 설치하고 측정 영역 전체와 표식을 보이게 한다. 내부 파라미터·렌즈 왜곡을 교정하고 해상도/초점/노출 변경 이력을 남긴다. 바닥에 실제 단위의 여러 기준점을 분포시켜 GT 좌표계를 정의한다. map으로 등록할 때 원점·축·회전·스케일과 변환 파일을 저장한다.

로봇 기준점은 몸통 강체 표식과 base_link 바닥 투영점 사이의 알려진 변환으로 정의한다. 머리·다리처럼 움직이는 점을 몸통 중심으로 가정하지 않는다. 바닥 homography를 높이 있는 표식에 바로 적용하면 원근 오차가 생긴다. 알려진 표식 크기와 카메라 pose로 3D 강체 pose를 구하거나, 표식 높이를 반영한 검증된 투영법을 사용한다. yaw는 방향을 식별할 표식/강체 모델로 계산하고 가림·대칭 모호성을 처리한다.

교정에 쓰지 않은 공간 점·방향·높이에서 오차를 검증한다. 위치 x/y 및 거리·yaw의 bias, 반복 표준편차, 상위 분위수와 최대 오차를 보고한다. 자의 분해능/측량 오차, 렌즈·원근·표식 장착 오차를 포함한다. 독립 검증 허용 오차는 측정하려는 효과의 크기와 오차 예산을 보고 사전에 정하고, 임의의 cm 수준을 성취했다고 쓰지 않는다. 교정 자료가 없거나 독립 검증에 실패하면 절대 GT로 인정하지 않는다.

## 영상 시각과 로그 연결

프레임 번호와 원본 PTS/time_base, 가능하면 노출 시각·하드웨어 clock, dropped/duplicate frame과 가변 fps 정보를 보존한다. `frame_index / nominal_fps`를 검증 없이 절대 시각으로 쓰지 않는다. host callback/저장 시각은 노출 시각과 다르다. 순차적 프레임이 있다는 사실은 ROS clock과의 정렬 증거가 아니다.

모터와 연결되지 않은 별도 광학/전기 공통 이벤트, 검증된 하드웨어 동기 또는 독립 시각 장치를 고려한다. 이벤트는 영상과 기록 PC 양쪽에서 식별 가능해야 한다. 기존 로봇 LED 제어 경로를 검토 없이 실행하는 방식은 사용하지 않는다. 시작과 끝 및 필요 시 중간 공통 단서로 offset과 drift를 측정하고 잔여 오차/검출 지연을 포함해 유효 구간을 명시한다. NTP/PTP 설정 이름만으로 정확도를 선언하지 않는다.

장치 A시각 t를 B시각으로 변환하는 부호와 단위를 파일에 명시한다. 시간 구간 밖에서는 변환하지 않는다. 네트워크 단방향 지연은 실제 동일 packet의 송신/수신 위치·ID와 양단 시계 오차가 있어야 한다. 송신 주기 또는 ROS header와 bag 시각 차이는 그 대체가 아니다.

## 추적 실패·속도 불확실성

가림, 표식 유실, 오검출, 교정 영역 이탈, 모션 블러에는 valid=false/결측 사유와 시작·끝 프레임을 기록한다. 장시간 보간으로 실제 궤적처럼 메우지 않는다. 보간을 분석에 쓴다면 원본과 별도로 방법·최대 구간·제외 기준을 사전 지정한다.

위치의 시간 차분은 위치 오차와 시각 오차를 증폭한다. 속도 구간/필터는 GT 측정률과 오차 예산에 맞춰 고정하고, 필터 지연과 가장자리 제외를 보고한다. 명령 시작·실제 이동 시작·목표 도달의 검출 정의 및 불확실성을 별도로 정한다. 추정 궤적에 맞춰 GT 변환을 학습하지 않는다.

## 보존할 자료와 합격 판단

카메라/렌즈/표식 ID, 고정 사진, 거리 기준 및 기준점 좌표, 내부/외부 교정 파일, 독립 검증 원시 자료·오차, 좌표 변환, 원본 영상/프레임 PTS, clock 연결과 잔여 오차·유효 기간, 추적 품질/결측, 담당자 서명을 trial에 연결한다. 보정 데이터와 검증 데이터는 분리한다.

P0는 장치·파이프라인을 비구동 상태에서 확인하는 단계다. 동적 추적의 정확도나 실물 이동을 검증했다고 주장하지 않는다. P1 승인 전에는 독립 기준의 정적 검증과 시간 연결 근거를 갖추고, 동적 정확도 검증 범위를 현장 승인 계획에 포함한다.
