# Phase 3B-2B Standard MAPPO 기준선 결과

측정일2026-11-19. 정상 정보 전달을 보장하는4대 통제 환경에서 독립 시드5개를 실제 학습·평가했다. 아래 값은 저장된 코드·checkpoint·raw에서 계산했다. CAH-MAPPO나 새 인계 구조는 구현하지 않았다. 보호 Holdout 400개는 사용하지 않았다.

## 1. 실행 범위와 동결

과거 모델을 이어 학습하지 않고 시드101/211/307/401/503에서 가중치·optimizer를 독립 초기화했다. 학습 사건 스트림도 서로 겹치지 않는다. 각100,352스텝, 총501,760스텝, 시드당3,136에피소드다. 별도 비용 측정512스텝은 본실험 반복에 포함하지 않는다.

Actor146→64→64→10, Critic141→64→64→1, Tanh, 공유 Actor, 기존 feed-forward MAPPO/PPO/GAE를 유지했다. 보상·하이퍼파라미터·32초 평가·구역 위험도·선택 기준은 학습 전에 동결했다. 세부 규약은 `PHASE3B2B_PROTOCOL_KO.md`, 기계 설정은 `main_v1/frozen_plan.json`과 `future_comparison_contract.json`이다.

학습은 작업1~3개를 랜덤화하고 주 평가는3개로 고정한다. 중요도1/2/4, 기한20/24/28초, 발생2/4/6초, 용량1이다. 센서 반경100m/잡음0/무선 지연0이므로 제한 공간의 현재 작업이 실제 센서 경로로 관측된다. Critic 상태를 Actor에 복사하지 않는다. 아직 발생하지 않은 작업은 Actor에 노출되지 않는다. 고장·손실·강한 관측 제한은 제외했다.

새 비최종 공통 benchmark는 위치 변화200개와 작업 조건 변화200개, 총400개 물리 시나리오다. 각 시드 결정적400회, 확률적1,200회(같은400개×반복3회)를 평가했다. 슬롯 진단은 이 중 사전 지정32개에서6순열을 두 모드로 평가하며 확률적 반복 수는1이다. 같은 세계의 반복·순열을 독립 학습 결과라고 세지 않는다.

5개 모델의 선택과 해시를 모두 동결한 뒤 benchmark를 생성·평가했다. 그 결과를 보고 모델·보상·예산을 바꾸지 않았다. 주 모델은 일반 슬롯 학습이며 순열 증강을 자동 적용하지 않았다. 이전 단일 시드 증강 실험은 초기화/데이터가 달라 이번5시드와 동등한 효과 비교로 사용하지 않는다.

## 9. 재현성·보존·산출물

전체152개 회귀/신규 테스트를 실제 실행하여20.574초에 통과했다. 기존134개와 신규18개이며 skip/failure/error0이다. episode 경계에서 저장·복원한 다음 rollout/업데이트가 중단 없는 실행과 정확히 같은지, 독립 초기화·미래 정보 차단·Critic 미사용 추론·마스크·보상 재구성·시드 단위 통계를 검증했다.

원시 로그 전수 감사의 최종 상태와 상세 계수는 `phase3b2b_outputs/audit_v3/audit.json`에 기록한다. 최초 감사에서는 Episode Return의 step별 누적과 Python3.12 부동소수 합산의 차이 약9e-16을 발견했다. 원본 학습/평가값은 바꾸지 않고 감사의 보상 합에만 절대오차1e-12를 허용했다. 다른 Ground Truth 지표는 정확 비교를 유지했다. 실패한 감사 로그도 보존했다.

실행 경로·명령·선택 checkpoint는 `PHASE3B2B_README_KO.md`, 고정 규약은 `PHASE3B2B_PROTOCOL_KO.md`에 있다. `analysis_v1/all_metrics.csv`에 시드별/정책별 전체 지표를 제공한다. 학습·Validation 곡선, benchmark 비교, 공백-응답 관계 그림은 `figures_v1/`에 저장했다.

## 10. 결론과 다음 단계

정상 전달 통제 환경의 Standard MAPPO 독립5시드 기준선을 확보했다. 확률적 실행의 실패·드문 긴 공백·중복 요청·남은 슬롯 편향을 기준 결과에 그대로 포함했다. 높은 성공률을 실제 로봇, 고장·지연·심한 관측 제한, 또는 책임 인계 학습의 성공으로 확장하지 않는다.

이번 조건에서는 기본 역할을 유지하는 중앙 Fixed도 성공100%/공백0%였다. 따라서 신경망이나 복잡한 인계 구조가 항상 필요하거나 우수하다고 입증한 실험이 아니다. Phase 4의 규칙 인계 비교는 정보량·준비 행동·할당 비용과 응답-공백 관계를 분리해야 한다. 설계는 `PHASE4_RULE_HANDOVER_PLAN_KO.md`에 정리했고 구현은 시작하지 않았다.

CAH-MAPPO, 원격 접속, 실물 구동, 새 설치/환경 변경, Git 커밋·푸시는 수행하지 않았다. 이 단계 보고 후 다음 승인을 기다린다.
