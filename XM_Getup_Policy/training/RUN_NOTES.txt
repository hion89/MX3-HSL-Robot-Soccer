[ 변경 — 네 가지 ]

  1) 팔 기본자세 (사용자 지정)     mx_bot.py XM_robot04_getup.init_joint_pos
         r_shoulder_pitch  0.0  -> -0.3
         l_shoulder_pitch  0.0  -> +0.3
         r/l_shoulder_roll 0.0  -> 0.0   (동일)
         r_elbow_pitch    +1.5  -> +1.0
         l_elbow_pitch    -1.5  -> -1.0
     use_default_offset=True 이므로 이 값이 **액션 원점**이자 스폰 자세다.

  2) 종료 목표도 같은 값     getup_v1_2_env_cfg.py _WALK_READY_POSE.update(...)
     원래 _WALK_READY_POSE 는 **보행 로봇 기본각**을 그대로 썼다. 다리는
     그게 맞지만 팔은 보행이 ±2.967(170도, 완전히 접힘)이라 기상 원점
     (±1.5)과 1.5 rad 벌어져 있었다. walk_ready_pose / walk_pose_deadline
     이 그 값을 목표로 삼아 **기립 후에도 팔을 계속 접으라고 요구**했다.
     초기=종료로 맞추면 기립 후 팔에 남는 압력이 0 이다.
     다리·목은 그대로.  확인: check_armpose.py 6/6 일치, 리밋 안.

  3) _PRONE_HEIGHT  0.110 -> 0.0815    (재측정, 필수)
     팔이 덜 접혀 몸통이 2.8 cm 더 내려앉는다. 앙와위는 0.0567 로 불변
     (등이 바닥이라 팔 영향 없음). mx_bot 주석의 "기본각을 바꾸면 이 값도
     다시 재야 한다" 를 따랐다.
     스폰 검증 (smoke_prone_v12.py, 512 env): 발사율 15/55/90 도 전부 0.0 %,
     안착 복와위 0.0815 / 앙와위 0.0567, g_x 부호 정상.

  4) getup_overshoot  -60 -> -10
     실기에서 문제없던 55300 의 값이다. 270 도 우회를 못 막지만 사용자가
     "일단 270 도 굴러도 된다" 고 확인했다. 우회 교정은 실기 안정 후 재시도.

  ※ 함께 맞춘 것: _CURR_PENALTY_STEPS (0,0) / _CURR_PENALTY_FROM_LEVEL 0
    48600 이 이 값으로 학습됐다. from_level=5 를 주면 레벨 5 까지 페널티가
    꺼졌다 켜지는 전이가 생기고, 그게 정책을 흔든다 (1 판 arate 16 배 악화).
  ※ 유지: _CURR_SUCCESS_THRESHOLD 0.8  (없으면 앙와위 성공만으로 승급해
    복와위를 안 배운다 — V2 12 판이 그랬다)
