# 속도 0 보행 러너 기록 분석 — 2026-11-05

실물 관절 목표를 보내지 않은 시험의 기록을 분석했다. 현재 자세는 초기 기립 자세로 유지됐다.
이 보고서는 실제 균형 유지나 보행 성공을 판정하지 않는다.

## 확인된 입력과 실행

- CSV 906행 = HOLD_START 47행 + 실제 추론 RUN 859행.
- CSV SHA256: 3ea70087338429b85b40dfd931631c1754f4e716380f901cdd1c6201318d81cf.
- 보행 모델 v0_6 13500 SHA256: 72e2b8d88bac39feb97bc7789e0a67e4675650713c6e4528988a32f96831fbb1.
- 전 구간 cmd_vx/vy/wz=0. 모델 출력은 유한값이다.
- 실제 추론 간격으로 계산한 주기는 약 47.994Hz. 간격 median=20.0ms, p99=45.2ms,
  max=47.1ms이며 858개 간격 중 36개가 30ms를 넘었다.
- 실제 추론 시간 median=.290ms, p99=2.194ms, max=6.429ms.
  긴 출력 간격의 원인을 추론 처리시간만으로 확정할 수 없다.

## 최대 무릎 차이는 초기 자동 위상 구간

| 시작 후 시각 | 상태 | 위상 주파수 |
|---:|---|---:|
| 0.0352초 | HOLD_START / STOPPED | 0Hz |
| 1.0121초 | RUN / WALKING | 2Hz |
| 2.0104초 | RUN / STOPPING | 0Hz |
| 2.0297초 이후 | RUN / STOPPED | 0Hz |

기록의 WALKING은 러너 내부 위상 상태다. 실물은 움직이지 않았다.
원본 resolve_gait_frequency는 auto 모드에서 첫 hold 이후 속도0 지속 시간을 새로 세며,
stop_delay_s=1.0이 지나기 전에는 gait_frequency=2.0을 반환한다.
따라서 이번 초기 1초의 제자리 위상은 코드와 일치한다.

- 왼쪽 무릎 최대 차이: 1.3503초, current=-1.217981rad, target=-1.646598rad,
  delta=-0.428617rad(-24.558도), WALKING/phase=.68/f=2Hz.
- 오른쪽 무릎 최대 차이: 1.6104초, current=1.216447rad, target=1.631840rad,
  delta=+23.800도, WALKING/phase=.20/f=2Hz.
- STOPPED 구간의 왼쪽 무릎 최대 차이는 4.969도다. 24.558도가 끝까지 지속된 것은 아니다.

## 모델 출력 재현 및 정지 모드 대조

PC의 별도 분석 환경에서 NumPy1.26.4/ONNXRuntime1.23.0 CPU를 사용했다.
원본 소스의 프레임/히스토리 구성 함수를 AST로 추출하여 그대로 사용했다.
과거 5프레임의 기록 관절/IMU/위상/이전 액션으로 854행을 재구성했으며,
기록된 raw action과의 최대 차이는 0.000001878이다.
관측 순서/히스토리 재구성의 수치 재현은 확인됐지만 물리 관절 축의 정답 검증은 아니다.

다음으로 같은 기록된 정지 관절·IMU 피드백을 유지한 채 위상 관측만 처음부터
stop=(cos1,sin0,freq0)으로 두고, 이전 액션 히스토리는 새 모델 출력으로 갱신했다.
실제 모터나 ROS는 실행하지 않았다. 최초 hold의 상세 센서 기록은 비어 있어
첫 RUN 센서 값을 5회 복제하고 이전 액션0으로 재생을 시작했다. 이 초기화 가정을 명시한다.

| 관절 | 원래 auto 기록 전체 최대 차이 | stop 재생 전체 최대 차이 | 원래 기록 마지막 5초의 중앙 차이 |
|---|---:|---:|---:|
| 왼쪽 무릎 | 24.56도 | 4.65도 | -4.37도 |
| 오른쪽 무릎 | 23.80도 | 9.32도 | +9.20도 |
| 오른쪽 골반 pitch | 15.30도 | 15.38도 | +14.07도 |
| 왼쪽 골반 pitch | 14.33도 | 14.38도 | -12.28도 |

처음부터 stop으로 시작하면 이번 입력에 대한 초기 무릎 위상 변화는 줄어든다.
그러나 골반/발목 등의 정지 목표 차이는 남는다. 정지 명령은 초기 관절 각도 고정을 뜻하지 않는다.
새 목표에 실제 관절·IMU가 반응하지 않은 기록 재생이므로 그 차이가 올바른 균형 보정인지,
물리 연결 시 수렴하는지 여부는 이 분석으로 판정할 수 없다.

기록된 목표 중 모델 URDF 관절 한계를 넘는 값은 없었다.
URDF 범위 안이라는 사실은 모터 허용 부하, 자가 충돌, 지지 안정성 검증을 대신하지 않는다.
기본 자세/보정값/가중치를 임의로 변경할 근거로 사용하지 않는다.

## 적용할 시작 순서와 다음 검증

  이번 분석에서는 러너 소스나 가중치를 변경하지 않았다.

  실물 모터와 보행 정책 프로세스를 띄우지 않는 분리 시험이다.
- 그 결과에 따라 명령 신선도 보호와 정지 경로를 확정한 뒤,
  목표 범위/제한된 자세 인계/실제 저속 시험을 진행한다.
